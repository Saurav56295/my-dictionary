# My Dictionary

A beginner-friendly Python dictionary program. Enter an English word to look up its meanings, pronunciation, and example sentences.

## Requirements

- Python 3
- An internet connection

The program uses the free [Dictionary API](https://dictionaryapi.dev/) and Python’s built-in libraries. No extra packages are needed.

## Run the program

Open a terminal in the project folder and run:

```powershell
python dictionary.py
